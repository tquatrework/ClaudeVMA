## Règles métier respectées

- **Mémo** : seul l'élève peut créer chapitres et items (formateur → message readonly, pas de bouton)
- **Carnet** : parent_financeur → redirect /forbidden ; RP → redirect /forbidden (Phase 1)
- **Page spéciale** : bouton visible uniquement pour le RP ; le RP choisit `hiddenFromStudent`
- **Cahier** : formateurs, RP, AP, TI peuvent écrire ; sélecteur de visibilité dans le formulaire
